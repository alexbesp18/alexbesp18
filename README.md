# I build AI systems that refuse to ship unverified output.

**[manager-13f](https://github.com/alexbesp18/manager-13f)** — SEC 13F filings → verified one-page intelligence sheets. Filings mix common stock with put and call rows, and reading them all as ordinary longs can invert a filer's book; this tool reads them correctly, and refuses to guess when a filing's number scale is ambiguous.

**[ops-log](https://github.com/alexbesp18/ops-log)** — the public operating record of my automation fleet. Failures are published alongside wins, with the fix each one got.
